# CAREFLOW 90-Second Demo Script

## Live Path

1. Open the CAREFLOW patient app and frame the problem: discharge is one of healthcare's most fragile handoffs.
2. Upload the pneumonia discharge PDF, or explain that the same path accepts pasted discharge text.
3. Point to the agent progress timeline: Intake, Summary, Medication, Risk, Education, then Conversation.
4. Show the recovery snapshot, today's plan, medication timeline, red flags, and follow-up checklist.
5. Ask the chat: "Can I take ibuprofen with these medications?"
6. Highlight that the answer references the plan, avoids approving a new medication, and redirects the patient to a doctor or pharmacist.
7. Switch to the pitch deck and close with insurance value: fewer avoidable readmissions, better adherence, and clearer recovery coordination.

## Fallback Path

1. If PDF parsing fails, use the visible paste area or sample note fallback.
2. If live AI is slow or unavailable, use the deterministic sample recovery plan.
3. If chat is unavailable, read the golden ibuprofen answer from the prepared backup.
4. Keep the story the same: CAREFLOW converts confusing pneumonia discharge instructions into a structured recovery workflow.
